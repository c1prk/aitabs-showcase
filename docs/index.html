What it does

Given a raw guitar recording, the pipeline isolates the guitar, detects individual notes with pitch and timing, and maps each note onto a specific string and fret — producing structured note data that can be exported to standard tab/MIDI formats.

separate_guitar
→
detect_notes + detect_onsets
→
map_sequence (string/fret DP)
→
export (GP5 / MIDI)

Every note carries a consistent schema through the whole pipeline:

{ start, end, pitch_midi, string, fret, confidence, source }

Engineering notes

  • Pluggable detector backend so BasicPitch variants (and future guitar-specialized models) can be A/B scored through the same eval harness.
  • Held-out eval set is never trained on; false-positive/false-negative buckets from analyze_errors.py drive every filter/threshold change, not intuition.
  • Rhythm/notation layer evaluated separately (position F1, note-value accuracy, tie handling, tempo-map behavior) since notated time and audio time diverge under rubato.
  • License-clean by design: training/eval data restricted to permissively-licensed sources (GuitarSet), no non-commercial dependencies.
